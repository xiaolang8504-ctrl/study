# 智错本产品说明书（V1.0）

> 一期产品形态：学生 PC Web 端；学生移动端与教师端纳入二期
> 文档状态：产品规划稿，可用于需求评审、UI 设计、研发拆期和验收
> 规划基线：基于当前仓库已有错题、OCR 导入、教材、作业、复习计划与提醒能力

## 1. 产品定义

### 1.1 产品愿景

把“发现错题—整理错题—理解错误—按时重练—验证掌握”变成一条低摩擦闭环，让学生少做无效重复，教师更快发现共性薄弱点，家长能看懂进步而不是只看分数。

### 1.2 核心目标

1. 单题采集平均用时不超过 15 秒，整页试卷采集后 60 秒内可完成确认。
2. 新增错题中，完成订正并进入复习计划的比例达到 60%。
3. 到期复习任务 7 日完成率达到 55%，复习后 30 日掌握率达到 70%。
4. 教师查看班级薄弱点并生成专项练习的操作不超过 5 步。

### 1.3 非目标

- 一期不做完整在线课堂、即时通讯和通用教务系统。
- AI 生成内容不能直接替代教材答案或教师判断；低置信度结果必须由用户确认。
- 不以题库数量作为唯一竞争点，优先保证采集、订正、复习闭环。

## 2. 用户与场景

| 角色 | 核心诉求 | 高频场景 | 核心权限 |
|---|---|---|---|
| 学生 | 快速收题、真正掌握 | 拍试卷、订正、每日复习 | 管理本人错题与计划 |
| 家长 | 帮助整理、了解进步 | 代拍错题、查看周报、提醒 | 绑定并切换孩子；不可替代作答 |
| 教师 | 发现共性问题、精准布置 | 班级分析、标注、专项组卷 | 查看授权班级，布置与点评 |
| 学校管理员 | 管理组织与合规 | 班级、教师、教材、权限 | 本校范围配置与审计 |
| 平台运营 | 维护资源与质量 | 题库、微课、AI 质检 | 脱敏数据与内容运营 |

#### 竞品结论

1. **采集已是基本盘。** 去手写、裁边、整卷扫描和 Word/PDF 输出正在同质化，必须做好，但不宜成为唯一卖点。
2. **打印是强反馈，但不是掌握。** 支持 A4/便携打印，同时用二维码或题号把纸面结果回流到作答记录。
3. **家长是重要操作人。** 支持多孩子和代采集；订正与掌握反馈仍必须由学生完成，避免污染画像。
4. **诊断必须可解释。** 显示“考什么、为什么错、缺哪一步、下一步练什么”，并展示样本量与置信度。
5. **差异化在闭环可信度。** 用独立作答证据和跨间隔保持确认掌握，而不是仅凭看过解析或点击“会了”。

### 3.4 差异化定位

产品一句话：**一款能证明“这道错题后来真的会了”的智能错题系统。**

- **先收得快：** 低置信度才打扰用户，拍完整页后批量确认。
- **再讲得清：** 答案、错因、前置知识和下一步动作汇成诊断卡。
- **最后有证据：** 只有未看答案的独立作答和跨间隔保持后，系统才判定掌握。

## 5. 功能需求

### 5.1 错题采集

#### FR-C01 多方式录入

- 拍一道：自动找边、透视矫正、阴影去除；支持补拍答案/解析。
- 拍整页/试卷：先生成页面，再自动框选题块；用户可合并、拆分、删除、调整边框。
- 相册：最多一次 20 张；按拍摄顺序处理。
- 文件：一期支持 PDF、DOCX、XLSX，单文件不超过 50MB/100 页；生成异步任务。
- 手动：题干必填；支持富文本、LaTeX、图片和选项。
- 断点续传：退出后保留 24 小时采集草稿。

#### FR-C02 智能处理流水线

`上传 → 安全扫描 → 图像增强 → 版面分析 → 切题 → OCR/公式识别 → 题库匹配 → 知识点/难度预测 → 用户确认`

- 每个字段保留置信度；低于阈值以橙色标记。
- 原图、净化图、结构化文本分开保存，可切换对照。
- 去手写默认为建议结果，不覆盖原图。
- 失败任务支持重试；OCR 不可用时仍允许“仅保存图片”。

#### FR-C03 批量确认

- 卡片展示题图、识别题干、科目、知识点及置信度。
- 支持全选、批量设置来源/教材/章节、跳过、保存草稿。
- 重复检测：同用户题干指纹 + 图片感知哈希；提示“已收录”，允许仍然添加。

#### FR-C04 来源关联

- 来源类型：考试、测验、作业、日常练习、自学、其他。
- 可关联作业/试卷实体，记录名称、日期、分数、教师与原文件页码。

### 5.2 错题管理

#### FR-W01 分类检索

- 结构化维度：学段、年级、学科、教材版本、章/节、知识点、题型、难度、来源、错误类型、状态、时间。
- 全文搜索覆盖题干、答案、解析与标签；命中词高亮。
- 保存常用筛选；支持卡片/列表视图。

#### FR-W02 详情与订正

- 详情页分为题目、我的作答、答案解析、学习记录四区。
- 订正流程：填写/拍摄错答 → 查看答案 → 选择错因 → 写订正 → 自评掌握。
- 状态机：`待订正 → 已订正 → 复习中 → 已掌握 → 已归档`；重练错误可回到“复习中”。
- 自动操作必须写入时间线，保留来源及修改人。

#### FR-W03 标签

- 系统错误类型：概念、计算、审题、步骤、记忆、粗心、方法、其他。
- 支持自定义标签；同义标签可由管理员合并。
- AI 标签只作建议，用户确认后生效。

#### FR-W04 导出与组卷

- PDF/Word 支持题目版、答案版、双栏、A4、题间留白、二维码。
- 组卷支持手选与按条件抽题；可设置题量、难度比例、知识点比例及去重。
- 分享采用有期限、可撤销链接；默认 7 天，禁止公开检索。

### 5.3 智能复习

#### FR-R01 排期

- 新订正错题自动入计划；用户可关闭某科目。
- 默认间隔：1、2、4、7、15、30 天；根据四级反馈动态提前或延后。
- 四级反馈：忘记、模糊、记得、熟练；反馈后立即展示下次日期。
- 每日上限、提醒时间、周末策略、考试冲刺模式可配置。

#### FR-R02 重练

- 默认隐藏答案；支持草稿板、拍照作答、计时与“稍后再做”。
- 查看答案后必须提交反馈；记录耗时、答案暴露、反馈和是否正确。
- 打印练习附题目二维码/短码，扫码回填独立正确或错误；未回填的打印行为不计掌握度。
- 可按科目、知识点、错误类型创建专项练习。

#### FR-R03 举一反三

- 优先推荐题库中经过审核的相似题；AI 变式题必须标注“AI 生成”。
- 保持考点不变，可调整数字、条件、问法和难度；生成前做可解性校验。
- 用户可举报答案错误/超纲/重复，问题题目立即降权。

#### FR-R04 学习路径

- 输入：知识点掌握度、前置依赖、错题频率、最近反馈、考试日期。
- 输出：每日 10–30 分钟任务，顺序为“前置补缺 → 当前薄弱 → 间隔巩固”。

### 5.4 数据分析

#### FR-A01 个人画像

- 掌握度不等同于正确率，综合最近反馈、间隔、独立作答和题目难度计算。
- 展示学科概览、知识点树、薄弱 TOP10、错因占比、近 7/30/90 日趋势。
- 数据不足时展示样本量，少于 3 题不做强结论。

#### FR-A02 复习效果

- 指标：到期完成率、首次重练正确率、30 日保持率、平均掌握用时、逾期量。
- 对比“复习前/复习后”，不使用无法解释的单一综合分。

#### FR-A03 报告

- 学生周报：新增、订正、掌握、复习完成、薄弱点与下周建议。
- 教师班级报告：知识点覆盖、错误率、共性错因、学生分层；小于 5 人不展示公开排行。

### 5.5 题库与资源

- 题库按学段、学科、教材、章节、知识点、题型、难度建立索引。
- 题目需经过版权、答案、解析与知识点质检；记录版本与下架状态。
- 微课/同步课/真题可关联知识点；从错题详情跳转时定位到对应片段。
- 外部题库以 provider + external_id 去重，保留授权范围与到期时间。

### 5.6 班级与协同

- 学生通过邀请码/二维码加入班级；家长需绑定学生后查看。
- 教师仅查看所授班级授权数据；可查看聚合错题，不默认查看学生原始手写内容。
- 教师可布置“补充错因、完成订正、专项重练”任务，并设置截止时间。
- 学生提交后教师可点评、退回；优秀范例公开前需学生/家长授权并匿名化。

### 5.7 用户、设置与安全

- 支持学生、教师、家长、校管、运营角色；一个账号可拥有多个身份。
- 支持小学、初中、高中及扩展学段；科目和教材按学段配置。
- 云端数据传输加密、敏感字段加密存储；提供导出、注销、备份与恢复。
- 儿童账户采用最小化采集，不展示行为广告；人脸、声纹不是必需信息。
- 操作审计覆盖查看、导出、分享、删除、角色和授权变更。

## 6. 关键业务规则

### 6.1 状态与掌握判定

| 状态 | 进入条件 | 退出条件 |
|---|---|---|
| 待订正 | 新收录 | 完成订正必填项 |
| 已订正 | 有正确答案、错因和订正 | 自动进入计划 |
| 复习中 | 存在有效复习项 | 连续两次“记得/熟练”且间隔 ≥15 天 |
| 已掌握 | 达到掌握阈值 | 再次答错或用户撤销 |
| 已归档 | 用户归档已掌握题 | 用户恢复 |

### 6.2 掌握度建议公式

`掌握度 = 40% 最近独立正确率 + 25% 间隔保持 + 20% 反馈可信度 + 15% 难度修正`。答案已暴露的练习不计为独立正确；所有权重可配置并做 A/B 验证。

### 6.3 AI 置信度

- ≥0.90：自动填充；0.70–0.89：填充并提示确认；<0.70：不自动提交。
- 科目、题干切分和答案识别属于关键字段，即使高置信度也必须在批量确认页可见。

## 8. 数据模型增量建议

在现有 `wrong_question`、复习计划/项目/记录、教材、作业和用户权限表基础上新增：

- `question_capture_task`、`question_capture_page`、`question_region`：异步采集与切题。
- `wrong_question_source_ref`：试卷/作业及页码关联。
- `knowledge_point`、`knowledge_point_relation`、`question_knowledge_point`：知识图谱。
- `wrong_question_tag`、`user_tag`、`wrong_question_tag_rel`：结构化标签。
- `question_bank_item`、`question_variant`、`learning_resource`：题库与资源。
- `class_member`、`teacher_class_subject`、`correction_task`、`task_submission`：班级协同。
- `learning_metric_daily`：日粒度画像快照，避免实时扫明细。
- `share_link`、`data_consent`、`audit_log`：分享、授权与审计。

关键改造：现有 `learningPoint`、`errorLabels` 保留为展示快照，同时新增关联表；现有状态值通过迁移映射到新状态机，避免直接破坏线上数据。

## 9. 非功能要求

- 性能：列表 P95 < 800ms；详情 P95 < 500ms；单页识别 P95 < 20s；批量任务可查询进度。
- 可用性：核心 API 月可用性 99.9%；上传与识别解耦，识别故障不影响浏览复习。
- 容量：图片对象存储 + CDN；原图设置生命周期，缩略图长期保存；大文件分片上传。
- 兼容：一期支持 Windows 10+/macOS 12+，Chrome/Edge 最近两个大版本，设计基准宽度 1440px，最低 1280px。
- 无障碍：正文与背景对比度不低于 4.5:1；关键操作不只依赖颜色。
- 可观测：采集任务 traceId、OCR provider、耗时、置信度、人工修正率全链路记录。

## 10. 埋点与核心指标

| 漏斗 | 事件 |
|---|---|
| 采集 | capture_start → upload_success → ocr_success → confirm_submit → question_created |
| 订正 | correction_start → answer_reveal → reason_selected → correction_submit |
| 复习 | review_task_expose → review_answer_reveal → feedback_submit → next_due_generated |
| 组卷 | paper_create → rule_confirm → preview → export/publish |

北极星指标：**每周完成有效复习并在下一间隔保持掌握的错题数**。护栏指标：OCR 人工修正率、AI 题举报率、逾期率、通知关闭率、7 日删除率。

## 11. 版本规划

### 一期：学生 PC 闭环（6–8 周）

- 学生 PC：首页、图片/扫描仪/文件采集、切题确认、错题本、订正、今日复习、个人组卷、学情与设置。
- 结构化状态、错因与标签；PDF/Word 导出；个人基础报告。
- 复用现有复习服务，补齐采集任务、扫描仪适配和审计。
- 首发只承诺三件事做到极致：整页 60 秒收完、诊断卡说清错因、复习结果能证明掌握。

### 二期：移动与教师协同（8–12 周）

- 学生移动端：相机/相册采集、移动复习、系统推送、多端同步。
- 教师 PC 端：班级、订正任务、班级洞察、教师组卷与点评。
- 家长身份、多孩子管理与学生周报。

### 三期：智能与资源（10–12 周）

- 审核题库、相似题、AI 变式题、微课关联、个性化路径。
- 家长周报、多孩子切换、学校管理与更细数据授权。

### 暂缓

- 泛社交、公开排行榜、开放聊天、覆盖全部考试类型、未经审核的全自动 AI 组卷。

## 12. 上线验收与风险

### 12.1 上线门槛

- 20 组真实试卷切题召回率 ≥95%，关键字段识别准确率 ≥90%。
- 采集、订正、复习、导出、删除/恢复主链路通过；弱网与 OCR 失败可恢复。
- 权限矩阵、未成年人隐私、分享撤销、数据导出/注销通过专项测试。
- 老数据迁移可回滚，复习排期结果与旧逻辑抽样一致。

### 12.2 主要风险与应对

| 风险 | 应对 |
|---|---|
| OCR/切题不稳定 | 置信度、人工框选、仅图保存、多供应商降级 |
| AI 答案错误 | 审核题优先、可解性校验、显著标识、举报与降权 |
| 功能过重导致弃用 | 首页只突出“拍错题/今日复习”，高级能力渐进披露 |
| 教师越权查看 | 班级科目授权、聚合默认、敏感查看审计 |
| 标签和知识点脏数据 | 结构化字典、同义合并、版本化知识图谱 |

## 13. 待产品评审决策

1. 首发载体优先小程序还是原生 App；本稿默认小程序/H5 验证闭环。
2. OCR、去手写、公式识别采用自建还是供应商组合，需按真实试卷样本评测。
3. 题库与微课版权来源和商业模式。
4. 学校版与家庭版数据边界、付费主体及功能差异。
