# 智错本现有系统优化与新版规划

> 范围：一期只建设学生 PC Web；学生移动端、家长端、教师端进入二期。
> 原则：优先复用仓库已有错题、OCR、复习排期、提醒、教材、作业和权限能力。

## 1. 当前产品判断

现有系统已经具备“错题录入—订正—复习排期—反馈—历史”的后端闭环，问题主要不在有没有功能，而在产品表达和数据结构：

- 默认进入错题表格，首页没有承接学生今天该做什么。
- 错题页偏管理后台，一屏字段过多，核心动作“订正/复习”不突出。
- OCR 仅有 A4 图片导入，缺少异步任务、整卷分页、切题调整和低置信度确认。
- `learningPoint`、`errorLabels` 是字符串，无法支撑可靠的知识图谱和标签统计。
- 已有复习聚合数据未充分用于首页、学情和行动建议。
- 系统管理、学生学习功能混在同一信息架构，应通过角色菜单隔离。

## 2. 本轮已落地

- 默认入口调整为学习首页。
- 首页接入现有 `initializeReviewHome` 聚合接口。
- 首页新增今日任务、掌握率、连续复习、逾期、7 日排期、薄弱知识点和快捷入口。
- 品牌和导航文案从“后台管理”调整为“学生学习空间”。
- 错题归档更名为“我的错题本”，A4 导入更名为“图片识别导入”。
- 账号操作收纳为下拉菜单，减少顶部工具栏噪声。

## 3. 一期目标与范围

### 3.1 核心目标

1. 学生登录后 5 秒内知道今天要做什么。
2. 单页试卷从上传到确认错题不超过 60 秒。
3. 新增错题完成订正的比例达到 60%。
4. 到期复习任务 7 日完成率达到 55%。
5. 掌握判定必须有未看答案的独立作答证据。

### 3.2 一期页面

| 优先级 | 页面 | 建设内容 |
|---|---|---|
| P0 | 学习首页 | 今日任务、排期、薄弱点、行动入口 |
| P0 | 我的错题本 | 卡片/列表切换、结构化筛选、批量操作 |
| P0 | 错题详情/订正 | 诊断卡、错因确认、订正、原图对照、时间线 |
| P0 | 今日复习 | 遮答案、草稿状态、答案解析、四级反馈 |
| P0 | 采集中心 | 图片/扫描仪/PDF、异步进度、切题、批量确认 |
| P1 | 错题组卷 | 原错题 + 变式题、Word/PDF、打印回填码 |
| P1 | 学情报告 | 掌握率、30 日保持率、错因分布、薄弱 TOP10 |
| P1 | 学习设置 | 教材、科目、每日上限、提醒与数据备份 |

## 4. 迭代计划

### Sprint 1：入口与闭环可见（已启动，1–2 周）

- 新学习首页与默认路由。
- 学生菜单文案和布局优化。
- 错题列表操作重新排序：订正/复习优先，编辑/删除收纳。
- 首页、复习首页统一指标口径。

验收：真实数据可展示；空数据、接口失败、逾期任务场景可用。

### Sprint 2：错题详情与订正（2 周）

- 新增独立详情页，替代弹窗承载复杂内容。
- 增加结构化错因、难度、章节和知识点关联。
- 建立状态机：待订正 → 已订正 → 复习中 → 已掌握 → 已归档。
- 记录状态变化、答案暴露和修改时间线。

验收：未完成订正不能进入已掌握；查看答案的练习不计独立正确。

### Sprint 3：PC 采集中心（2–3 周）

- 上传任务、分页、失败重试和断点草稿。
- 图像增强、去手写副本、自动切题、合并/拆分。
- OCR 字段置信度和批量确认。
- 重复题检测与仅保存图片降级。

验收：20 组真实试卷切题召回率 ≥95%，关键字段准确率 ≥90%。

### Sprint 4：组卷与学情（2 周）

- 按科目/知识点/状态/难度生成个人练习。
- PDF/Word 题目版与答案版分离。
- 打印短码回填练习结果。
- 增加错因分布、30 日保持率和薄弱 TOP10。

## 5. 技术增量

### 5.1 数据模型

- `question_capture_task/page/region`：采集任务、页面和题块。
- `knowledge_point` 与关联表：替代单一知识点字符串。
- `wrong_question_tag_rel`：替代逗号分隔标签。
- `wrong_question_timeline`：订正、状态、答案暴露与复习事件。
- `practice_paper/item/result`：个人组卷和纸面回填。
- `learning_metric_daily`：学情日快照。

现有字符串字段保留为展示快照，采用双写和迁移脚本渐进升级。

### 5.2 API

- `GET /api/student/home`：统一学生首页，减少多接口拼装。
- `/api/capture/tasks/**`：上传、进度、切题调整、确认。
- `/api/wrongQuestion/{id}/correction`：提交订正与错因。
- `/api/practicePaper/**`：生成、预览、导出、结果回填。
- `/api/learningReport/**`：趋势、薄弱点和复习效果。

### 5.3 权限与菜单

- 学生仅看到学习首页、采集、错题本、复习、组卷、学情、设置。
- 系统用户、角色、部门、资源、字典只对管理员开放。
- 所有查询默认按当前 `createId`/学生 ID 隔离，不接收前端传入用户 ID 作为信任依据。

## 6. 二期规划

- 学生移动端：相机/相册采集、移动复习、系统通知、多端同步。
- 教师 PC：班级洞察、订正任务、点评、班级组卷和学生报告。
- 家长端：代采集、多孩子切换、周报；不能替学生提交掌握反馈。
- 题库与资源：审核题库、相似题、AI 变式题、微课和真题。

## 7. 核心指标

- 北极星：每周完成有效复习并在下一间隔保持掌握的错题数。
- 采集：开始上传 → OCR 成功 → 确认 → 创建错题转化率。
- 订正：新增错题 7 日订正率。
- 复习：到期完成率、首次独立正确率、30 日保持率、逾期率。
- 质量：OCR 人工修正率、切题调整率、AI 答案举报率、7 日删除率。

## 8. 暂不建设

- 一期不建设手机端、教师端、家长端。
- 不建设公开排行榜、泛社交、即时聊天和完整在线课堂。
- 不允许未经审核的 AI 答案直接标记为标准答案。
