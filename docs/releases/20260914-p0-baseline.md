# 20260914 P0 发布基线

## 发布身份与范围

- 发布名称：`智错本学习系统 P0`。
- 服务名：`gateway-service`、`system-service`、`schedule-service`。
- 本发布仅覆盖学生 PC Web 及系统管理能力；不包含移动端、教师、班级或学校域。
- 历史 `com.yunshang.budget` Java 包名仅为二进制兼容层，不代表部署服务、Nacos 数据集或业务权限仍属于供应链系统。

## 迁移规则

1. 只有 `study-module-system/src/main/resources/sql/generated/` 中按 `yyyyMMdd_` 开头命名的脚本，会由 `GeneratedSqlMigrationRunner` 在应用启动时执行。
2. 执行器以 MySQL 命名锁串行运行，记录脚本名、MD5、开始/结束时间、成功或失败原因。已在历史表中的脚本禁止修改。
3. 非 `generated` 目录中的 SQL 是新环境初始化或历史参考脚本；它们不能与受管增量脚本混合重复执行。
4. 回滚一律新增反向受管脚本，例如 `20260915_revert_xxx.sql`；禁止删除、改写已发布脚本或手工删除迁移历史。
5. 每一批上线必须在发布单中记录：脚本清单、备份点、预期耗时、回滚脚本、责任人和预发演练结果。

## 本批验收

| 项目 | 验收方式 | 通过标准 |
|---|---|---|
| 迁移幂等 | 同一数据库连续启动两次服务 | 首次执行新增脚本，第二次不重复执行；历史表校验和不变。 |
| 迁移防篡改 | 修改已登记脚本内容后启动 | 启动失败，审计表写入 `FAILED`，不继续执行业务启动。 |
| 并发启动 | 两个实例同时启动 | 仅一个实例取得命名锁并执行迁移，另一实例等待或超时失败。 |
| 回滚 | 预发备份库执行反向脚本 | 结构和数据恢复到发布前状态，迁移审计和发布单留痕。 |
| P0 主链路 | 学生账号完成采集、订正、复习和报告 | 无跨账号数据可见；失败页面保留原图并可重试。 |
| 学习证据 | 查看错题详情的学习时间线 | 录入、采集确认、订正、答案曝光、复习反馈及自动掌握均可追溯来源与时间。 |

## 不可自动化的环境验收

本仓库不包含生产 Nacos、MySQL、Redis、对象存储、OCR 或邮件凭据。部署前必须依照 [P0 发布运行手册](../p0-baseline-and-security-runbook.md) 在预发环境完成真实文件、真实 OCR 样本及多账号权限验收，并将结果附到本发布单。
