# 智错本：学生 PC Web 功能对比与开发任务清单

> 盘点日期：2026-09-21。范围：学生 PC Web、已有的家长网页协作、内容管理和服务端支撑。不规划手机端、教师端、班级/学校端。下文的“已有”表示工作区中有实现，不代表已在生产环境验收。任务估算用 S（约 1–3 人日）、M（约 4–8 人日）、L（约 9–15 人日），含开发和针对性验证，不含外部服务采购及大规模历史数据清洗。

本清单按当前代码重新盘点，更新了 [2026-09-01 产品对比](2026-09-01-product-comparison-and-roadmap.md) 中家长网页、导出和采集能力的旧状态。阶段周数是假设约 4–5 名开发与测试人员可并行投入的粗估，排期前应根据实际人力和样本评测结果重算。

## 一、现状判断

本仓库已有 Vue 2 + Element UI 学生网页端，以及登录、错题、图片/PDF 异步采集、OCR 切题与人工修框、订正记录、知识点/错因、间隔复习、专项练习、学情报告、题库审核、家长网页协作和系统管理接口。采集、练习、家长周报都有页面和服务代码。`mvn -pl study-module-system -am test -q` 于盘点日通过：20 个测试报告，33 个用例，0 失败；`frontend/npm run build` 通过，但入口包约 1.21 MiB，构建提示体积超标。未连接生产 Nacos、MySQL、Redis、OCR、文件存储和邮件服务做端到端验收。

| 能力 | 代码现状 | 关键判断 |
|---|---|---|
| 学生首页、错题详情、订正 | 已有页面与接口 | 工作流已形成；需校准状态规则、减少录入/订正步骤。 |
| 图片/PDF 采集与 OCR | 已有异步任务、逐页状态、框选/拆合、置信度、重试和仅存图片 | 支持 JPG/JPEG/PNG/PDF；实际识别质量需要真实样本验证。 |
| “净化图” | 已有原图/净化图对照 UI | 服务端目前仅转换成灰度 PNG，**没有实现去手写笔迹**。 |
| 复习掌握 | 已有答案曝光前草稿凭证、四级反馈、独立作答字段、掌握度 | 代码计算独立作答，但自动变更为“已掌握”的条件没有直接检查该字段；应先修正。 |
| 组卷与导出 | 已有在线练习、浏览器打印、短码回填、异步 PDF/DOCX 导出 | 服务端文档渲染只写文本；题图、公式和选项排版需补齐。 |
| 个人学情 | 已有掌握率、薄弱点、错因、30 日保持率、日快照和备份 | 部分报表仍按用户拉取整批记录再内存聚合；需统一口径并压测。 |
| 题库与内容 | 已有审核、去重、版本、举报、来源/授权字段和相似题 | 需要内容准入、授权到期控制和题目质量闭环；`questionvariant` 目前主要是实体与 Mapper。 |
| 家长网页 | 已有邀请/确认/解绑、只读概览、周报、代上传待学生确认 | 属于已开发能力，需角色隔离、多账号越权和真实通知链路验收。 |
| 安全与交付 | 已有 JWT/RBAC、文件签名下载、权限缓存刷新、受管 SQL 迁移 | 前端路由只校验本地 token；权限必须以后端为准。现有大量未提交改动，发布基线尚需冻结。 |

## 二、同类产品对比

竞品列仅依据官网公开功能说明，不把官网宣传的准确率、用户量或学习效果视为独立验证结果。

| 参照产品 | 官网公开能力 | 本项目对应能力 | 下一步 |
|---|---|---|---|
| [试卷宝](https://shijuanbao.aizuoye100.com/) | 试卷上传、去笔迹、知识点练习、AI 相似题、Word 导出和网页体验 | 已有采集、知识点练习、导出基础；真正去笔迹和复杂题目导出待补 | 优先做真实卷面质量和无损导出。 |
| [师孔子智能错题本](https://www.shikongzi.com/) | PC 批量图文录题、一图多题、Word/PDF 输出、复习评测和本地备份 | 已有批量采集、切题、复习和 JSON 备份；重度编辑与排版体验待验证 | 优化批量确认和可编辑练习卷。 |
| [喵喵机](https://www.paperang.com/cn/pc/download) | 错题整理、组卷重练、薄弱学情报告、同类题练习及打印生态 | 已有组卷、报告、同类题和普通打印 | 重点完善纸面结果回填、证据与报告，不需要硬件适配。 |
| [AI 错题本](https://www.aierrorbook.com/help) | 知识点/错因/能力层级诊断、知识图谱、学习路径和在线重考 | 已有知识点、错因、专项练习及在线作答；前置关系和路径解释不足 | 先建立版本化知识结构与可靠证据，再做智能推荐。 |

**产品主线：**让学生快速收题、完成订正，并用“答案曝光前作答 + 跨间隔再次正确”解释为什么判定为掌握。官网功能对比说明采集、组卷和分析已经是常见能力，差异更可能来自低摩擦的 PC 整卷处理和可信的学习证据。

## 四、建议先做的第一批任务

1. **B01、B02、B05**：先把现有工作区变成可复现的试点基线，并证明对象归属与主链路正确。
2. **B03、B04**：修正掌握判定及相关报告口径。这是本产品核心可信度问题。
3. **B07、B08**：纠正“净化图”描述，建立 OCR/卷面质量基线，再决定去笔迹技术方案。
4. **C07、C08**：在进入常规推广前，确保含题图/公式的练习卷和纸面回填有真实可用的学习价值。

试点核心指标建议先测基线，再设目标：上传→确认→建题转化率、每页采集/确认耗时、7 日订正率、到期复习完成率、独立正确率、30 日保持率、导出成功率、跨账号越权成功次数（必须为 0）。

## 五、不纳入本清单

学生手机端/小程序、教师/班级/学校工作台、硬件打印机适配、公开社交排行榜与在线课堂。现有家长功能只按网页端受控协作完善。
