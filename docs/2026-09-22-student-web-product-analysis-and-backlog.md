# 智错本学生 PC Web：同行功能对比与产品需求开发清单

> 更新于 2026-09-22。只讨论学生 PC Web 的产品功能；家长网页列为可选扩展。不规划手机端、教师端、班级端。本清单按当前仓库的页面和接口判断“已有/部分/缺少”，不讨论测试、发布、部署或验收。竞品依据官方公开页面，宣传效果不作为已证实结果。

## 一、同行产品在做什么

| 产品 | 官方公开的相关功能 | 值得借鉴的产品设计 | 对本系统的意义 |
|---|---|---|---|
| [试卷宝](https://shijuanbao.aizuoye100.com/) | 整卷上传、自动整理错题、抹除笔迹、知识点组练、AI 举一反三、教材同步卷、地区真题、Word 导出和网页体验 | 把“录题省时间”和“旧卷变新卷”连成一个流程 | 本系统已有 OCR 与采集，但灰度图不去笔迹，导出的 PDF/DOCX 主要是文本；这是最直接的体验差距。 |
| [师孔子智能错题本](https://www.shikongzi.com/) | PC 批量图文录题、一图多题、图文编辑、Word/PDF 组卷、复习评测、提醒和本地备份；官网还提到从网页/Word 粘贴题目 | 重度 PC 用户的批量编辑、粘贴和可编辑输出 | 本系统有修框、拆合和备份，但缺少面向 PC 的剪贴板快录、整批属性编辑及完善的富文本排版。 |
| [喵喵机](https://www.paperang.com/cn/pc/download) | 错题试卷整理、组卷重练、薄弱学情报告、同类题练习 | 错题必须能顺畅回到练习，而不止于收藏 | 本系统已具备相应模块，需要把题目选择、纸面输出、再次作答连成连续体验。无需硬件适配。 |
| [小猿搜题](https://www.yuansouti.com/) | 题目解析、分步讲解、错题自动收录、教材同步练习等 | 学生遇到不会的题时，先得到“下一步怎么想”的帮助 | 本系统有答案/解析字段，缺少结构化分步提示和从当前题直达针对性练习。视频讲解需要合法内容来源，后置。 |
| [作业帮](https://zyb.zuoyebang.com/) | 搜索答疑、视频讲解、真题试卷、个性化推荐练习、薄弱点分析、教材同步复习 | 内容资源和练习入口衔接紧密 | 本系统不宜先追求海量题库；应先让已有审核题库和个人错题发挥作用，后续再引入有授权的真题/同步题。 |
| [AI 错题本](https://www.aierrorbook.com/help) | 知识点、错因、能力层级三维诊断；知识图谱、学习路径、专项训练和在线重考 | 报告不仅展示统计，还能给出下一项学习任务 | 本系统有知识点、错因、报告和在线练习，但能力层级、前置知识关系及可解释学习路径尚未形成。 |

这些产品的共同点是**录入后能迅速生成下一次练习**。本项目应把定位收敛为“学生在 PC 上高效处理整张试卷，订正后持续重做，知道自己哪类题真正学会了”。拍题搜全网答案、直播授课、硬件打印并不是这一阶段需要复制的产品边界。

## 三、按产品价值排序的功能任务

优先级：**F1 = 下一轮先做**，让现有主链路明显更省时、更好用；**F2 = F1 完成后扩展练习效果**；**F3 = 依赖内容或算法投入的长期功能**。每项只写用户可见功能及必要的数据/交互改动，不包含验收任务。

## 四、开发顺序建议

1. **先做 F1-01、F1-02、F1-03、F1-08、F1-09。**它们直接改善 PC 产品最重要的“整卷进入系统，再变成可重练的卷子”。
2. **接着做 F1-05～F1-07、F1-10，以及 F2-01、F2-05。**让整理、订正、解析、报告都能导向下一次练习。
3. **去笔迹 F1-04 可与第一阶段并行调研/开发。**它是同行明显卖点，但必须以“原题不丢、可回退”为产品前提。
4. **再做 F2 的计划和相似题，最后考虑 F3 的真题、知识图谱与生成题。**这几类功能依赖内容质量和稳定的题目结构；目前不宜先建设大而全的题库。

产品取舍上，建议把首个鲜明体验定义为：**“上传一张或一整张试卷，在 PC 上快速整理错题，并立即生成一份内容完整、可编辑、可再次作答的练习卷。”**这个体验把本项目现有能力串起来，也直接对应同行最常见的使用场景。

## 五、功能开发进展（2026-09-23）

- **F1-01 已完善：**采集中心支持单题快录/整卷录入、截图粘贴、图片或 PDF 拖拽、文件质量提示、重复文件拦截、逐文件上传进度、上传失败重试、文件顺序调整，以及 24 小时内上传/任务草稿恢复。
- **F1-02 已完善：**多页试卷提供带待确认数量的页面缩略图、原图与题框工作台、右侧题目字段、上/下一低置信题、当前页/低置信/全部题块批量归类、快速批选，以及新增、拆分、跳过和确认快捷键；单题块归类值由服务端统一校验并归一化。
- **F1-08 已开发第一版完整主链路：**错题列表可把勾选题目直接加入组卷篮；按条件智能选题的预览结果也可调序、移除；练习卷可设置名称、题量、难度、每题留白、答案位置及原图/灰度预览/仅文字题面模式，保存后在线作答、打印、Word/PDF 导出均沿用卷面设置。服务端会重新校验错题归属和题库可用状态，并按组卷篮顺序保存题目。
- **F1-08 与 F1-09 的题图链路已打通：**在线练习、浏览器打印和服务端 PDF/DOCX 使用统一的题图素材清单；采集题按题块坐标裁剪，题库受管图片可嵌入标准 DOCX/PDF，灰度图未生成时回退原图。灰度预览仍明确保留笔迹，不作为去笔迹能力宣传。

下一项优先继续补 **F1-03/F1-09**：在已打通题图与题块裁剪的基础上，完善公式、表格、图片选项、单双栏和复杂分页保真，并建设可编辑的题目素材模型。
